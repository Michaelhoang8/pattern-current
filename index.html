        Search semantics & bounds
        

          This is literal, case-sensitive Aho–Corasick matching, not regular-expression search.
          Patterns are not Unicode-normalized. Offsets count Unicode code points, start at zero, and
          use an exclusive end. They are not byte offsets or grapheme-cluster positions.
        

        

          The worker carries automaton state between complete-code-point chunks. It records the
          first 2,000 matches and first 128 chunk boundaries. Full counts remain exact: state visits
          propagate through failure links after scanning, without enumerating every match in a dense
          output stream.
        

        

          Use 1–100 patterns, each up to 256 code points, with at most 5,000 pattern code points in
          total. Text is limited to 250,000 code points and 500,000 UTF-16 units. UTF-8 file imports
          are limited to 1 MB. Unpaired surrogates and malformed UTF-8 are rejected.
        

        

          This app splits an already loaded text into code-point chunks. It does not model a network
          byte decoder or split UTF-8 byte sequences. All files and calculations stay in the
          browser; save before refreshing.
